# CoMatcher

CoMatcher è un concept di app pensato per aiutare studenti e lavoratori a trovare persone con cui studiare o lavorare in spazi condivisi.

## Il progetto

La progettazione comprende:

- definizione del target e dei profili degli utenti;
- identità visiva: logo, colori, font e icone;
- organizzazione delle funzioni principali e secondarie;
- ontologia degli elementi dell'app, tra cui utenti, incontri, messaggi, luoghi e feedback;
- wireframe della schermata iniziale.
